# VOJAZH
Производственная практика для колледжа
init: начальная структура проекта ПМ.09
feat(db): создание БД турагентства, таблицы tours, bookings, индексы
feat(api): реализация REST API на Flask (аутентификация, туры, бронирования)
feat(ui): адаптивная сетка каталога туров, mobile-first CSS
perf(db): добавлен составной индекс idx_tours_country_price
perf(server): HTTP-кэш каталога через @cache.cached(timeout=600)
perf(client): lazy-load изображений, CSS-спрайт иконок, defer скриптов
feat(variant-16): завершение проекта, документация, скриншоты Lighthouse
